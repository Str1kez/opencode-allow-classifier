# Классификатор shell-команд вместо статических ask-правил

**Status**: accepted

OpenCode V2 проверяет shell-вызовы по упорядоченным правилам
`{action, resource, effect}` с базовой политикой `*/* allow`: всё, что не
поймано правилом, выполняется без подтверждения. Статические правила ловят
форму команды, а не риск — `*-exec*` пропускает `xargs`, `docker exec` и
`kubectl exec`, но требует подтверждения на безобидный `find -exec grep`.
Поэтому мы ставим `shell: * → ask` и добавляем плагин `allow-classifier`,
который понижает `ask → allow` по контексту: команда, cwd, агент и последнее
сообщение пользователя. Плагин живёт в отдельном репозитории
`Str1kez/opencode-allow-classifier`; dotfiles подключает его в
`opencode.jsonc`.

Порядок решения: hard-ask (sudo, установка пакетов, `git push`, `rm` вне cwd,
миграции) → статический allowlist read-only команд с гардом на секреты →
in-memory кэш → Jev через `ctx.experimental.generate.decisions`. Порог 0.9,
таймаут 3 с, любая ошибка оставляет `ask`. `deny`-правила не трогаем: хук для
них не вызывается вообще.

## Рассмотренные альтернативы

- **Точечные ask-правила.** Новые exec-формы проходят молча, а существующие
  правила уже мажут по форме.
- **`opencode --auto`.** Одобряет всё, что не запрещено явно, без контекста и
  без возможности объяснить решение.
- **Классификатор, который умеет только `allow → ask`.** Не увидит команду,
  которая прошла базовую политику: хуку нечего понижать.

## Последствия

- Каждый новый shell-вызов стоит около 0.9 с, пока не попал в кэш. Jev на
  free-тире бесплатен, платный — копейки.
- Плагин обязан fail-open в сторону `ask`: таймаут, ошибка провайдера,
  `Generate.ErrorAnswer` — человек видит промпт.
- Allowlist обходит read-правила для секретов, поэтому в нём есть гард на
  `.env`, `.ssh`, `id_rsa`, `credentials` и `/etc/`.
- Allowlist ограничен cwd: чтение `~/…`, `..` и абсолютных путей вне проекта
  просит подтверждение, а программа по пути исполняется только из доверенных
  каталогов. Рекурсивный поиск с ignore-флагами или корнем в cwd тоже
  спрашивает: файлы, которых нет в argv, иначе обходили бы гард секретов.
- Выбор модели живёт в TUI (`/classifier`), рантайм-оверрайд — в серверном
  `ctx.storage`, дефолт — в `opencode.jsonc`.
