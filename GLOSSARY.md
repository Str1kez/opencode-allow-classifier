# opencode-allow-classifier

Глоссарий предметной области плагина: как shell-команды получают вердикт.

## OpenCode permissions

**Правило разрешения**:
Запись `{action, resource, effect}`, которая матчит вызов инструмента по глобу.
Побеждает последнее совпавшее правило.
_Avoid_: политика, ACL

**Триггер**:
Правило с эффектом `ask`, из-за которого вызов попадает в классификатор.
Команда без триггера не классифицируется вообще.
_Avoid_: хук, перехват

**Вердикт**:
Итоговое решение по вызову: `allow` или `ask`. `deny` вердиктом не является —
он выносится до классификатора и не пересматривается.
_Avoid_: решение, ответ

**Понижение**:
Смена эффекта `ask` на `allow` по результату классификации.
_Avoid_: автоодобрение, разжатие

**Auto mode**:
Режим, в котором каждый shell-вызов по умолчанию требует подтверждения,
а безопасные вызовы понижает классификатор.
_Avoid_: полный автопилот, yolo

**Hard-ask**:
Категория команд, которая всегда уходит человеку и не показывается классификатору.
_Avoid_: чёрный список, запрет

**Allowlist**:
Список read-only команд, которые получают `allow` без обращения к классификатору.
_Avoid_: белый список, safe list

**Контекст классификатора**:
Набор данных, на которых классификатор выносит вердикт: команда, рабочий каталог,
агент и последнее сообщение пользователя.
_Avoid_: окружение, промпт

**Jev**:
Модель System One, которая отвечает на типизированные вопросы вероятностями,
а не генерирует текст.
_Avoid_: LLM, классификатор
